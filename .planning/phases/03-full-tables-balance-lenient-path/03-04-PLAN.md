<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ContaPlusData → xlsx renderer | Renderer receives fully validated data from read(); the renderer itself does no I/O and makes no security decisions |
| CLI user input → lenient flag | --lenient is a boolean flag; no user-supplied string is parsed or evaluated |
| BALAN.SDO_CIERRE values → Decimal sum | Values come from read_table_raw() (ContaPlusReadError-wrapped); Decimal(str(None)) is avoided by None guard |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-12 | Denial of Service | BALAN DESCRIP/FORMULA columns up to 255 chars wide | mitigate | _autosize_columns caps at 50 chars (existing pattern in xlsx.py); _autosize_columns_from_offset inherits the same cap |
| T-03-13 | Tampering | SDO_CIERRE None values in Decimal sum | mitigate | Explicit `if row[sdo_idx] is not None` guard per RESEARCH.md Pitfall 1; test_balan_no_banner_when_balanced verifies no crash |
| T-03-14 | Information Disclosure | ProblemEntry.reason text in Problemas sheet | accept | Reason strings are program-generated English text from ContaPlusReadError.message; no raw OS paths, no secrets, no user PII |
| T-03-15 | Tampering | BalanceRow Decimal values written as float to openpyxl | accept | float(Decimal) is lossless for 2-decimal-place values; openpyxl stores as IEEE 754 double; display precision is handled by ACCOUNTING_FMT number format |
| T-03-16 | Spoofing | --lenient flag bypasses strict validation | accept | This is by design (D-01); strict mode is the default; lenient is an explicit user opt-in; tax-workbench always calls the strict path |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in Phase 3 |
</threat_model>
